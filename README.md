# 📊 Commerce Sales 500 – 2025 Data Analysis

## 📌 Project Overview

This project is a **2025 Commerce Sales Data Analysis project** created using **Microsoft Excel**.

The dataset contains **500 sales transactions** and is designed to demonstrate practical data-analysis skills including data cleaning, Excel formulas, PivotTables, and data visualization.

The project is suitable for a **Data Analyst portfolio** and demonstrates how raw sales data can be transformed into meaningful business insights.

---

## 🎯 Project Objectives

- Analyze 500 sales transactions from 2025
- Calculate total sales and total profit
- Analyze sales by product category
- Create a Category-wise Sales PivotTable
- Create Column and Pie Charts
- Practice Excel data-analysis techniques
- Present business results in a clear and professional format

## 📊 Analysis Performed

### 1. Total Sales

Total sales were calculated using an Excel `SUM` formula.

```excel
=SUM(Sales_INR)
```

### 2. Total Profit

Total profit was calculated from the Profit column.

```excel
=SUM(Profit)
```

### 3. Category-wise Sales

A PivotTable was created with:

- **Rows:** Category
- **Values:** Sum of Sales_INR

This provides a comparison of sales performance across product categories.

### 4. Column Chart

A **Column Chart** was created to compare sales between categories.

### 5. Pie Chart

A **Pie Chart** was created to show each category's contribution to total sales.
